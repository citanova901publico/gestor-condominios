# Gestor de Condominios

Prototipo navegable del producto **Gestor de Condominios**.

## Estructura

- `index.html`: prototipo principal.
- `css/styles.css`: estilos responsivos.
- `js/app.js`: navegación e interacciones simuladas.

## Módulos incluidos

- Dashboard
- Estado de cuenta
- Pagos
- Reservas
- Visitas
- Incidencias
- Comunicados

## Ejecución local

Puedes abrir `index.html` directamente en el navegador o servir el repositorio con cualquier servidor HTTP estático.

Ejemplo con VS Code: usar la extensión Live Server y abrir `index.html`.

## Publicación

El prototipo está preparado para publicarse como sitio estático, por ejemplo mediante GitHub Pages.

> Los datos son simulados y se utilizan únicamente para validar UX, navegación y alcance funcional.
